# Ella · Complete Skill Labels & Icons — All Levels

**Design Reference · NavGurukul · August 2026**

Student-facing labels for all 118 skills across 6 transition levels. All labels 3–5 words, built to read clearly on a skill card when Zoe shows a growth moment after a conversation. Piyush's streamlined "I can" statements included for reference.

**Track key:** 🌸 Vocabulary · 🔵 Grammar · 🟣 Fluency

**Icon decision key:**
- ✅ **Reuse concept** — same visual idea works for the new skill statement, generate from the existing concept
- 🆕 **New concept** — skill concept changed enough that the old visual would mislead; needs a fresh concept

> Every skill needs a fresh generated asset either way (these are being built new in Claude Design, not recovered from old files). The distinction that matters is whether the **underlying visual idea** carries over, or whether the concept itself needs rethinking.
