The Memory response (`GET /users/me/memory`) is the single source of truth for a student's state. Every field maps to a database column or is computed from one.

---

## API Endpoint

```
GET /users/me/memory
Authorization: Bearer JWT_ACCESS_TOKEN
```

---

## Field Map

| Field | Type | DB Table.Column | Written by | When it updates |
|---|---|---|---|---|
| `id` | string | `users.id` | Auth | On first login |
| `device_id` | string | `users.device_id` | Auth | On first login |
| `profile.name` | string | `users.name` | Placement / Profile update | After placement or PUT /users/me |
| `profile.age` | int | `users.age` | Placement / Profile update | After placement or PUT /users/me |
| `profile.city` | string | `users.location` | Profile update | PUT /users/me |
| `level` | string | `users.level` | Placement / Judge | After placement or level-up |
| `first_session_done` | bool | `users.first_session_done` | Placement / Judge | After first placement or conversation |
| `interests` | list | `users.interests` | Placement | After placement (comma-separated in DB) |
| `last_time_recap` | string | Computed | Placement highlight OR session_analyses.zoe_recap | After placement or conversation judge |
| `placement` | object | `placements` table | POST /llm/placement-turn | After placement completes |
| `placement_garden` | object | Computed from `placements.confidence` | Placement | After placement completes |
| `owned` | list | `users.skills_progress["owned"]` | Judge | After conversation grading |

| `due_next` | object | `users.due_next` | Judge | After conversation grading |

| `persona_memory` | object | `users.persona_memory` | Judge | After conversation (facts extracted) |

## What Writes Each Field

### After Placement (`POST /llm/placement-turn` completes)
- `level` ← LLM assessment
- `interests` ← LLM detected interests
- `placement` ← record created
- `placement_garden` ← computed from confidence
- `last_time_recap` ← friendly recap from interests
- `first_session_done` ← set true (via POST /placements)

### After Conversation Judge (`POST /llm/judge`)
- `owned`, `emerging` ← skills that progressed
- `sightings`, `strength` ← evidence counts
- `due_next` ← next target skills computed
- `effort.times_spoken_total` ← incremented by turn count
- `units`, `last_topics` ← topic added to history
- `persona_memory` ← new facts extracted from conversation
- `last_time_recap` ← zoe_recap from judge (overrides placement recap)

### Computed on Read (not stored separately)
- `next_topics` ← fresh topics from LEVEL_TOPICS minus already-used
- `placement_garden` ← derived from latest placement confidence

---

## Database Tables Involved

| Table | Fields stored |
|---|---|
| `users` | level, name, age, location, interests, skills_progress (JSON), due_next (JSON), persona_memory (JSON), first_session_done |
| `placements` | level, unit_label, confidence, highlight, transcript_json, created_at |
| `session_analyses` | zoe_recap, best_moment_quote, correction_highlight, skills_evidenced, etc. |
| `conversations` | topic, header_title, completed, completed_at |
| `messages` | role, content, correction, turn_number |
