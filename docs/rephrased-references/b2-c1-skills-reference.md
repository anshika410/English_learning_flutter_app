## Open Items for Review

- **Prachi — Unit 4 has only 3 skills.** Confirm with Prachi whether this is intentional or if a missing skill needs to be added before finalising.
- **Prachi — Unit 2, Vocabulary:** "Compress a whole thought into a single noun phrase" removes the term *nominalisation* entirely. At C1 level, students may benefit from knowing the term. Offer alternative: "Use nominalisation — the rise in, the failure to act."
- **Prachi — Unit 2, Grammar:** "Use complex noun phrases and participle clauses naturally" retains the technical terms. Confirm if *participle clauses* is language students at this level should see on their card, or if a plain-language version is preferred: "Build dense, detailed phrases into a single sentence."
- **Prachi — Unit 5, Grammar:** "Make only rare errors — and catch them yourself" is the one label in the whole framework that references errors at all. At C1 this is the reality being described, but check whether even this phrasing is too deficit-adjacent. Alternative: "Your grammar is essentially clean and self-correcting."
- **Sael — Unit 1, Grammar:** ↕️ (up-down arrow) for sentence inversion is abstract. A custom illustration showing a flipped sentence structure would land much better here.
- **Sael — Unit 2, Vocabulary:** 📦 (box/package) for nominalisation — confirm this reads as "compressing an idea" and not just "a box." May need a custom illustration.
- **Sael — Unit 3, Grammar:** ♻️ for reference and substitution — works logically (reuse without repeating) but the environmental connotation of ♻️ might be confusing. Alternative: 🔁 or a custom illustration.
- **Sael — Unit 4:** Only 3 skills in this unit. If displayed on the garden with the same plot layout, consider whether the empty fourth plot needs a visual treatment or if the garden adapts to 3 naturally.
