# Ella · C1→C2 Skill Labels & Icons

**Design Reference · NavGurukul · July 2026**

Revised student-facing labels for all 19 skills across the 5 units of the C1→C2 path.
Original "I can" statements included for review and handoff.

**Track key:** 🌸 Vocabulary · 🔵 Grammar · 🟣 Fluency

> **Context:** This is the final transition in the framework. Per the source overview, the shift here is **mastery → artistry** — there are no new structures left to acquire. The change is depth of feel: vocabulary becomes instinctive, grammar becomes craft, and English reaches full communicative equivalence to a first language.

> **Structural note:** Step 4 ("Language as Identity") has only 3 skills — every other unit in this transition has 4. This is the same asymmetry pattern already flagged in B2→C1 Unit 4. Confirm with Prachi whether this is intentional (a lighter, more reflective unit) or an omission.

> **Revision note:** Labels below were tightened to a 4–5 word maximum per feedback — the first pass ran too long (6–10 words) for card-sized display.

## Open Items for Review

- **Prachi — Unit 4 has only 3 skills**, matching the same asymmetry already flagged in B2→C1 Unit 4. Worth resolving both at once rather than case-by-case — is a 3-skill unit an intentional, lighter "reflective" unit type that recurs near the top of the framework, or does each need a 4th skill added?
- **Prachi — this level asks Zoe to evaluate very abstract, identity-level claims** ("English is simply your language," "Let English be your bridge"). Unlike every earlier level, several of these are self-perception statements rather than demonstrable language behaviours. Worth a specific conversation on how — or whether — evidence-gathering for these differs from the skill-demonstration model used everywhere else in the framework.
- **Prachi — compression trade-off at this level specifically.** Tightening to 4–5 words meant some nuance from the original "I can" statements got cut (e.g. "authority and creativity" reduced to just "precision and warmth" in Unit 5, Fluency). At every other level this trade-off was clearly worth it; at C1→C2 the source statements were already carrying literary weight, so confirm the shorter versions still land, or whether this is the one level where a slightly longer label is justified.
- **Sael — icon reuse across the file.** Full cross-level icon audit is still outstanding; this file avoids repeating icons already used at A0→C1, but hasn't been re-verified against the compiled all-levels HTML.
- **Sael — abstraction ceiling.** Several concepts (🪄, 🌀, 🫂) are metaphor-level choices, not depictions — no concrete object exists to draw for "grammar as craft" or "language as identity." Likely the hardest unit in the framework to illustrate literally.
